# KidsWeb 월드맵 재설계 — 설계 문서

> 작성일: 2026-05-20
> 대상: KidsWeb 홈 화면을 평면 카테고리 그리드 → "곰곰이의 사계절 마을" 월드맵으로 전환

---

## 1. 개요

### 1.1 배경
기존 기획서(`Doc/01_기획서.md`, 2026-03-23)의 홈 화면은 10개 카테고리를
평면 2×5 그리드로 나열하는 구조다. claude.ai/design 시안 작업 중 사용자가
"게임 모드 진입 시 섬마을을 찾아가는 식의 메뉴 구성"을 떠올렸고,
검토 결과 유아(만 3~5세) 앱에서 월드맵 메뉴가 탐험감·진행감·동기부여 측면에서
효과적이라 판단해 홈 화면을 월드맵으로 재설계한다.

### 1.2 목표
- 평면 그리드 홈 화면을 가로 스크롤 월드맵으로 교체
- 10개 카테고리를 계절 테마의 "장소"로 변환
- 잠금 없는 자유 탐색 + 장소 꾸미기 기반 동기부여
- 서브메뉴 이하 화면 흐름은 변경하지 않음 (영향 최소화)

### 1.3 비목표 (YAGNI)
- 계절/장소 잠금·게이트 (좌절 요소 제거 위해 의도적 배제)
- 장소별 레벨·경험치 바 (별로 충분)
- 일일 출석 보상, 친구 경쟁/랭킹

## 2. 정보 아키텍처

### 2.1 전체 구조 — "곰곰이의 사계절 마을"

가로 스크롤 파노라마 맵. 봄→여름→가을 3개 계절 구역, 총 10개 장소.

```
←──────────────────  가로 스크롤  ──────────────────→

🌸 봄 동산 ▒▒▒▒▒ ☀️ 여름 바다 ▒▒▒▒▒ 🍂 가을 숲
─────────────────────────────────────────────────
🏡        🎨      🔷      🎵  │  📚    🔤    🔢  │  🤖    🧩    💻    💬
곰곰이집  색칠    모양    노래 │ 글자  ABC   숫자 │ 로봇  수수께끼 등대  친구
         언덕    꽃밭    폭포 │ 나무숲 모래사장 산 │ 공장  동굴         광장
```

### 2.2 계절-카테고리 분배

| 계절 | 컨셉 | 장소 (카테고리 id) |
|---|---|---|
| 🌸 봄 동산 | 표현·감각 (진입장벽 낮음) | 색칠 언덕 (coloring) / 모양 꽃밭 (shapes) / 노래 폭포 (music) |
| ☀️ 여름 바다 | 핵심 학습 3종 | 글자나무 숲 (hangul) / ABC 모래사장 (english) / 숫자 산 (math) |
| 🍂 가을 숲 | 사고력·응용·놀이 | 로봇 공장 (coding) / 수수께끼 동굴 (brain) / 반짝 등대 (computer) / 친구 광장 (social) |

### 2.3 핵심 원칙
- **잠금 없음**: 10개 장소 모두 처음부터 자유 접근. 계절은 진행 게이트가 아닌 시각적 구역.
- **자동 스크롤**: 맵 진입 시 오늘 실제 계절 위치로 자동 스크롤. 부모 설정에서 끄기 가능.
- **카테고리 잠금**: 부모 설정에서만 가능 (기존 와이어 13번 기능 유지).

## 3. 화면 흐름 & 인터랙션

### 3.1 화면 흐름

```
스플래시 (1.5초)
    ↓
월드맵 (홈)  ←─────────────┐
    ↓ 장소 터치             │
곰곰이 걷기 애니메이션 (1~2초)  │  (빠른 진입 ON 시 생략)
    ↓ 도착                  │
서브메뉴 (장소별)            │
    ↓ 기능 선택             │
활동 화면 (게임플레이)        │
    ↓ 완료                  │
칭찬 화면 → "홈으로" ────────┘
```

월드맵은 홈 화면만 교체한다. 서브메뉴·활동·칭찬 화면의 흐름과 구조는 변경하지 않는다.

### 3.2 월드맵 인터랙션

| 요소 | 동작 | 결과 |
|---|---|---|
| 빈 곳 좌우 드래그/스와이프 | 가로 스크롤 | 봄↔여름↔가을 이동 |
| 장소 터치 | 곰곰이가 그쪽으로 걸어감 (1~2초) | 도착 후 서브메뉴 진입 |
| 곰곰이 터치 | 랜덤 인사말 + 음성 | "어디로 갈까?" 등 |
| 별 카운터 터치 | 스티커 수집 화면 | Phase 2 |
| ⚙ 부모 버튼 | 3초 길게 누르기 | 산수 문제 → 부모 설정 |

### 3.3 곰곰이 걷기 애니메이션
- 곰곰이는 항상 맵 위 어딘가(마지막 방문 장소 근처)에 서 있다.
- 장소 터치 → 맵이 해당 장소로 자동 스크롤 + 곰곰이가 좌/우로 걸어가는 모션(다리 흔들 + 통통 튀기).
- 도착하면 장소가 살짝 커지며 반짝 → 0.3초 후 서브메뉴 페이드인.
- 걷는 동안 발자국 자국이 잠깐 남았다 사라진다.
- 너무 먼 경우(가을→봄) 걷기를 1~2초로 압축, 중간 구간은 빠르게 스크롤.

### 3.4 되돌아오기
- 서브메뉴/활동에서 ◀ 뒤로 → 월드맵 복귀 시 곰곰이는 그 장소에 그대로 서 있다(맥락 유지).
- 칭찬 화면 "홈으로" → 월드맵, 곰곰이는 방금 활동한 장소 옆.

### 3.5 엣지 케이스
- 걷기 애니메이션 중 다른 장소 터치 → 현재 걷기를 취소하고 새 목적지로 방향 전환.
- 맵 양 끝(곰곰이집 왼쪽 / 친구광장 오른쪽)은 고무줄 바운스로 더 못 감을 표시.
- 스크롤 중 실수 터치 방지 → 드래그 거리가 일정 이상이면 터치를 스크롤로 판정.

### 3.6 빠른 진입 옵션
- 부모 설정에 "빠른 진입" 토글 추가.
- ON일 경우 곰곰이 걷기 애니메이션(3.3)을 생략하고 장소 터치 즉시 서브메뉴로 진입.
- 기본값 OFF (걷기 애니메이션 표시).

## 4. 진행도 & 동기부여 시스템

잠금이 없으므로 동기부여는 "내가 마을을 가꾼다"는 성취감에 둔다.

### 4.1 별 (Star) — 기존 유지
- 활동 완료 시 1~3개 획득, 맵 우상단 누적 카운터.
- 칭찬 화면에서 별 획득 연출.

### 4.2 장소 꾸미기 (핵심 신규 요소)
장소를 방문하고 별을 모을수록 그 장소가 점점 예뻐진다.

| decorLevel | 단계 | 조건 | 장소 변화 |
|---|---|---|---|
| 0 | 새싹 | 미방문 | 장소가 흐릿/단순하게 표시 |
| 1 | 자람 | 1회 방문 | 장소 컬러·디테일 살아남 |
| 2 | 활짝 | 해당 장소 누적 별 5개 | 장식 추가 (꽃, 깃발, 작은 동물) |
| 3 | 반짝 | 해당 장소 누적 별 15개 | 반짝임 효과 + 곰곰이 친구 등장 |

맵을 스크롤하면 아이가 키운 장소들이 한눈에 보여 "더 가꾸고 싶다"는 동기가 생긴다.

### 4.3 오늘의 추천
- 맵 진입 시 곰곰이 말풍선: "오늘은 OO 어때?" (랜덤 또는 최근 안 간 곳).
- 추천 장소가 살짝 통통 튀어 시선을 유도한다.
- 강제 아님 — 아이는 무시하고 아무 데나 가도 된다.

### 4.4 진행도 시각화
- 각 장소 아래 작은 별 뱃지 (그 장소에서 모은 별 수).
- 부모 리포트용 전체 진행 띠 "마을이 70% 예뻐졌어요" (선택 구현).

### 4.5 데이터 모델
기존 `StorageService` 인터페이스를 확장한다.

```typescript
interface PlaceProgress {
  placeId: string        // 'coloring', 'hangul' ...
  visited: boolean
  stars: number          // 그 장소 누적 별
  decorLevel: 0 | 1 | 2 | 3
}
```

기존 `saveProgress(categoryId, data)` 인터페이스를 그대로 사용하므로
Phase 2 Supabase 전환 시 영향이 없다.

## 5. 컴포넌트 구조 & 기존 코드 통합

### 5.1 영향 범위 — 홈 화면만 교체

| 기존 (Plan 1 / sample) | 변경 |
|---|---|
| `app/page.tsx` 평면 그리드 | 월드맵으로 교체 |
| `CategoryCard` (120×120 카드) | `MapPlace` (장소 일러스트)로 대체 |
| `TimeBackground` | `WorldMapBackground` (계절 구역 + 시간대) |
| `lib/categories.ts` | `season`, `mapX`, `placeName` 필드 추가 |
| `StorageService` | `PlaceProgress` CRUD 추가 |
| `SubMenuPage` 이하 | 변경 없음 |

### 5.2 신규 컴포넌트

```
components/worldmap/
├── WorldMap.tsx           월드맵 컨테이너 (가로 스크롤 관리)
├── WorldMapBackground.tsx 봄/여름/가을 구역 + 시간대 그라데이션
├── MapPlace.tsx           장소 1개 (decorLevel별 외형, 별 뱃지)
├── Mascot.tsx             곰곰이 (idle / walking 상태머신)
├── SeasonZone.tsx         계절 구역 래퍼 (장식·경계)
└── RecommendBubble.tsx    "오늘은 OO 어때?" 말풍선
```

### 5.3 상태 관리 (Zustand 스토어 확장)

```typescript
interface AppState {
  // 기존: stars, isLoading, settings
  placeProgress: Record<string, PlaceProgress>  // 신규
  mascotAt: string          // 곰곰이 현재 위치 placeId
  fastEntry: boolean        // 빠른 진입 (부모 설정)

  visitPlace: (placeId: string) => Promise<void>  // 방문 기록 + decorLevel 갱신
  walkMascotTo: (placeId: string) => void         // 곰곰이 이동
}
```

### 5.4 곰곰이 상태머신

```
idle (서있기, 숨쉬기 모션)
  │ 장소 터치
  ▼
walking (목적지로 이동 + 맵 스크롤)
  │ 도착
  ▼
arrived (장소 반짝) → 0.3초 → 서브메뉴 진입
  │
  └─ 빠른 진입 ON이면 walking 건너뛰고 바로 arrived
```

### 5.5 단위 분리 원칙
- **MapPlace**: props로 `place`, `progress`, `onSelect`만 받는다. 내부 일러스트 로직은
  캡슐화되어, `decorLevel`만 바뀌면 외형이 자동 변경된다.
- **Mascot**: `targetX` prop을 받아 스스로 걸어간다. 월드맵은 "어디로 가라"만 지시하고
  애니메이션 디테일은 알지 못한다.
- **WorldMap**: 스크롤 위치·곰곰이·장소 배치만 조율한다. 데이터는 스토어에서 가져온다.

### 5.6 콘텐츠/코드 분리
장소 데이터는 `lib/places.ts`에 JSON 형태로 분리한다.

```typescript
{ id: 'coloring', placeName: '색칠 언덕', season: 'spring',
  mapX: 320, emoji: '🎨', categoryId: 'coloring' }
```

### 5.7 sample 코드 활용
claude.ai/design이 생성한 `sample/kidsweb-activities.jsx`의 활동 컴포넌트
(한글·수학·코딩 등)는 서브메뉴 이하라 그대로 재활용 가능하다.
월드맵만 새로 구현하면 된다.

## 6. 시각 디자인 방향

### 6.1 톤앤매너
- 톤 C(지브리 수채화)를 월드맵 기본 톤으로 추천. 가로 파노라마 자연 풍경과
  수채화 질감의 궁합이 좋고, 계절감 표현과 "마을" 정서에 부합한다.
- sample처럼 A/B/C 톤 전환은 유지하며, 최종 결정은 로컬 확인 후 한다.

### 6.2 계절별 색·분위기

| 계절 | 하늘/대지 | 장식 요소 |
|---|---|---|
| 🌸 봄 동산 | 연두 언덕 + 분홍 하늘 | 벚꽃잎 흩날림, 새싹, 나비 |
| ☀️ 여름 바다 | 청록 바다 + 파란 하늘 | 파도, 야자수, 조개, 햇살 |
| 🍂 가을 숲 | 주황 단풍 + 노을빛 하늘 | 낙엽, 도토리, 버섯 |

- 계절 경계는 자연스러운 그라데이션으로 섞는다 (딱 끊기지 않게).
- 시간대(아침/낮/저녁)는 계절 위에 하늘색만 추가 변조한다.

### 6.3 장소 표현
- 각 장소는 작은 건물/자연물 일러스트 (단순 카드 아님).
  - 색칠 언덕 = 무지개색 언덕 + 이젤
  - 글자나무 숲 = 글자가 열매처럼 달린 나무
  - 숫자 산 = 숫자가 새겨진 산봉우리
  - 로봇 공장 = 톱니바퀴 굴뚝 건물
- `decorLevel`에 따라 장식이 추가된다 (새싹→자람→활짝→반짝).
- 터치 영역은 일러스트보다 넉넉하게 (최소 100×100px 히트박스).

### 6.4 곰곰이
- 둥글둥글한 갈색 곰, 멜빵바지.
- 상태: 서있기(숨쉬기) / 걷기(다리·팔 흔들 + 통통) / 인사(손 흔들).
- 크기: 화면 높이의 약 1/6 (장소보다 약간 작게).

### 6.5 공통 규칙 (기존 유지)
- 폰트 `Gaegu` (손글씨체), 최소 20px.
- 터치 타겟 64px+.
- 둥근 모서리, 부드러운 그림자.
- 광고·외부링크 없음.

## 8. 요약

곰곰이의 사계절 마을 — 가로 스크롤 월드맵. 봄·여름·가을 3구역에 10개 장소.
잠금 없이 자유 탐색하며, 장소 터치 시 곰곰이가 걸어가 진입한다(빠른 진입 옵션 제공).
별을 모으면 장소가 4단계로 예뻐지는 "장소 꾸미기"가 동기부여 축이다.
홈 화면만 교체하고 서브메뉴 이하는 기존 구조를 유지한다. 톤 C(지브리 수채화)를 추천한다.
