## 2. 구현됐으나 서브기능이 부분 구현인 카테고리

기획서의 기능 목록 대비 실제 서브메뉴(`SUBMENUS`) / 활동이 축소되어 있음.

### 색칠놀이 (`color`) — 🟡
- ✅ 자유 색칠 (`FreeColoringActivity`), 영역 색칠 (`ColoringActivity`), 내 갤러리(localStorage 저장)
- 🟡 영역 색칠 도안 6종(사과·물고기·별·꽃·나비·공룡) — 기획서는 5카테고리 50장+
- ❌ 스티커 배치, 영역 색칠 "가이드 모드(이 부분은 무슨 색?)"

### 한글 (`hangul`) — 🟡
- ✅ 자음, 모음, 낱말
- ❌ 따라쓰기, 글자 조합(만들기), 단어 카드(플래시카드)

### 수학 (`math`) — 🟡
- ✅ 덧셈, 1~5 세기, 6~10 세기
- ❌ 숫자 따라쓰기, 크기 비교, 순서 맞추기, **뺄셈**, 도형 세기

### 음악 (`music`) — 🟡
- ✅ 피아노, 북, 실로폰 (Web Audio API 합성음)
- ❌ 따라치기, 동요 감상, 리듬 게임

### 두뇌게임 (`brain`) — 🟡
- ✅ 같은 짝(메모리), 패턴, 그림자
- ❌ 틀린그림찾기, 퍼즐 맞추기, 미로찾기, 순서 기억하기

### 코딩놀이 (`code`) — 🟡
- ✅ 단일 코딩 활동(`CodingActivity`) 동작
- ❌ 다단계 미션(20+ 스테이지), 반복 블록, 난이도 레벨 구성

## 3. 카테고리를 가로지르는 핵심 미구현 (기획 원칙 관련)

| 항목 | 상태 | 비고 |
|---|---|---|
| **음성 안내(TTS)** | ❌ | 기획 핵심 원칙("글자 못 읽는 아이용 음성"). `speechSynthesis`/음성 파일 없음. `VoiceGuide`는 시각 표시만 |
| **효과음(SFX)** | 🟡 | 피아노/음악의 `AudioContext` 합성 비프음만 존재(`activities.jsx:1585`). 범용 터치/정답 효과음 에셋 없음 |
| **부모설정 — 사용시간 제한** | ❌ | 설정 UI는 있으나 실제 동작 미연동(`timeLimit`이 설정 화면 밖에서 사용되지 않음) |
| **부모설정 — 음량 조절** | ❌ | 슬라이더 UI만 있고 실제 오디오 볼륨에 미연결 |
| **부모설정 — 카테고리 잠금** | 🟡 | UI 존재 / 월드맵 반영 여부 확인 필요 |
| **부모설정 — 학습 리포트** | 🟡 | UI 존재 / 실제 사용 통계 집계 미연동 |
| **부모설정 — 톤 A/B/C 선택** | ✅ | 실제 연동 완료 |
| **빠른 진입 토글** | 🟡 | `storage.js` 기본값 필드만 있고 토글 UI는 후속 |
| **보상 — 스티커 수집** | ❌ | 별 카운터 터치 → 스티커 화면(Phase 2) |
| **보상 — 레벨 뱃지** | ❌ | 카테고리별 초/중/고급 뱃지 |
| **별 적립** | ✅ | localStorage 영속화 |

## 4. 이미 잘 구현된 부분 (참고)

월드맵 홈("곰곰이의 사계절 마을"), 6개 카테고리 활동(색칠·한글·수학·음악·두뇌·코딩),
스플래시, 칭찬 화면, 자유/영역 색칠 + 갤러리 저장, localStorage 영속화(설정·별·진행도),
톤 A/B/C 선택, 1024×768 화면 맞춤 스케일, PWA(설치형 + 오프라인).

## 5. 권장 구현 우선순위 (제안)

기획서 9장 MVP 우선순위 + 현재 갭을 반영한 제안:

1. **음성 안내(TTS) + 효과음** — 전 기능에 영향, 기획 핵심 원칙
2. **부모설정 실연동** — 사용시간 제한·음량 (안전/사용성 직결)
3. **영어 학습** — 한글 구조 재활용 가능, MVP 우선순위 7위지만 재사용성 높음
4. **수학·한글·두뇌·음악 서브기능 보강** — 기존 카테고리 깊이 확장
5. **도형/색깔** — 수학과 연계
6. **컴퓨터·소셜** — 부가 기능
