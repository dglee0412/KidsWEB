# KidsWeb — Design Brief (for claude.ai/design)

> claude.ai/design에 붙여넣기 위한 압축 브리프.
> 한 번에 전체를 넣지 말고, 아래 **공통 컨텍스트**를 먼저 보낸 뒤
> 각 화면을 별도 메시지로 요청하는 방식을 권장합니다.

---

## 📌 공통 컨텍스트 (먼저 붙여넣기)

```
프로젝트: KidsWeb — 만 3~5세 유아용 교육 웹앱(PWA)
플랫폼: 태블릿 가로모드 1024×768 우선, 터치 기반
타겟: 글자 못 읽는 유아 → 큰 아이콘 + 음성 안내 + 즉각 피드백

디자인 원칙:
- 터치 타겟 최소 64×64px
- 폰트 최소 20px, 본문 24px+
- 고채도 원색 + 둥근 모서리(16~32px radius)
- 부드러운 바운스 애니메이션 (whileTap: scale 0.92)
- 광고/외부링크 절대 없음
- 한국어 UI

메인 구조:
- 홈 = 가로 스크롤 월드맵 "곰곰이의 사계절 마을" (봄·여름·가을 3구역, 10개 장소)
- 마스코트: 곰돌이 "곰곰이" 🐻 — 멜빵바지, 둥글둥글, 마을 안내자
- 흐름: 월드맵 → 장소 터치(곰곰이 걷기) → 서브메뉴 → 활동 → 칭찬

컬러 시스템 (카테고리별):
- 색칠놀이 #FF8A5C (주황)
- 한글     #95E1D3 (연두)
- 영어     #AA96DA (연보라)
- 수학     #FCF876 (노랑)
- 도형/색깔 #F38181 (분홍)
- 음악     #A8D8EA (하늘)
- 코딩     #98D6A6 (초록)
- 두뇌게임  #DDA0DD (자주)
- 컴퓨터   #87CEEB (스카이)
- 소셜놀이  #FFDAC1 (살구)
- Primary  #FF6B6B / Secondary #4ECDC4 / Accent #FFE66D
- 배경 #F7F7F7, 시간대별 그라데이션(아침-낮-저녁)

공통 컴포넌트:
- 뒤로버튼: 64×64 원형, 좌측 화살표
- 별 카운터: ⭐ + 숫자, 흰색 알약형, 우상단 고정
- 카테고리 카드: 120×120, radius 16px, 그림자
- 서브메뉴 카드: 200×180, radius 20px, 흰 배경
- 일반 버튼: 최소 160×64, radius 32px, 볼드

톤앤매너 후보 (이 중 하나를 지정하거나 비교해줘):
A. 밝은 원색 (Khan Academy Kids 풍, 고채도)1
B. 파스텔 (부드러운 톤, Lalaloopsy 풍)
C. 스튜디오 지브리 (수채화, 자연 텍스처)
```

## 🎨 화면별 요청 프롬프트 (하나씩 보내기)

각 항목을 위 공통 컨텍스트 뒤에 이어 붙여서 한 메시지로 보내세요.

### 1. 스플래시
```
스플래시 화면을 만들어줘.
- 중앙: 🌈 무지개 아이콘 + "KidsWeb" 큰 로고
- 하단: 빙글빙글 도는 ⭐ 로딩
- 배경: 하늘색→연보라 세로 그라데이션
- 1.5초 뒤 페이드아웃 전제
```

### 2. 홈 (메인) — 월드맵 "곰곰이의 사계절 마을"
```
홈 화면을 가로 스크롤 월드맵으로 만들어줘.
- 컨셉: 마스코트 곰곰이가 사는 사계절 마을. 가로로 긴 파노라마 맵.
- 계절 구역 3개 (왼→오): 🌸봄 동산 → ☀️여름 바다 → 🍂가을 숲
  계절 경계는 배경색이 자연스러운 그라데이션으로 섞임
- 장소 10개를 건물/자연물 일러스트로 배치:
  봄: 색칠 언덕🎨 / 모양 꽃밭🔷 / 노래 폭포🎵
  여름: 글자나무 숲📚 / ABC 모래사장🔤 / 숫자 산🔢
  가을: 로봇 공장🤖 / 수수께끼 동굴🧩 / 반짝 등대💻 / 친구 광장💬
- 맵 시작점(맨 왼쪽)에 곰곰이집🏡, 그 옆에 곰곰이🐻 캐릭터가 서 있음
- 추천 말풍선: 한 장소 위에 "오늘은 OO 어때?" 말풍선, 그 장소가 통통 튐
- 상단: 맵 제목 "곰곰이의 사계절 마을" + 우측 ⭐별 카운터
- 잠금 표시 없음 (10개 장소 모두 자유 접근)
- 장소 꾸미기 4단계: 흐릿(미방문) → 또렷(방문) → 🌸꽃 장식(별5+) → ✨반짝(별15+)
- 한 화면(1024px)에는 맵 일부만 보이고 좌우 스크롤로 탐색
- 배경: 봄(연두+분홍) / 여름(청록) / 가을(주황) 계절별 색감
```

### 3. 카테고리 서브메뉴 (색칠놀이 기준)
```
색칠놀이 서브메뉴 화면을 만들어줘.
- 상단바: ◀뒤로 / "🎨 색칠놀이" 타이틀 / ⭐별
- 본문: 2×2 그리드의 큰 카드(200×180)
  자유 색칠 🖌️ / 영역 색칠 🪣 / 내 갤러리 🖼️ / 잠금 🔒
- 카드 안: 큰 아이콘 + 기능명 + 짧은 설명
```

### 4. 자유 색칠 - 배경 선택
```
자유 색칠 진입 시 배경 선택 화면을 만들어줘.
- 상단: ◀뒤로 + "배경 선택"
- 큰 업로드 영역: 📤 "내 사진에서 배경 가져오기" (점선 테두리)
- 구분선 "── 또는 기본 배경 ──"
- 카테고리 탭: [동물] [풍경] [탈것] [캐릭터] [패턴]
- 4×2 썸네일 그리드: 🐱🐶🐰🦁🐘🦋🐟🦄
- 하단: 최근 사용 3개
```

### 5. 자유 색칠 - 캔버스
```
자유 색칠 캔버스 화면을 만들어줘.
- 상단바: ◀뒤로 / "자유 색칠놀이" / ↩되돌리기 / 🔄초기화 / 💾저장
- 좌측 메인: 큰 캔버스 (배경 이미지 위에 투명 레이어)
- 우측 세로 도구바: 🖍크레용 / 🖌붓 / ✏펜 / 🧽지우개 (각 64×64, 선택 시 강조)
- 하단 좌: 12색 팔레트 + 🌈확장 (원형 48px 색상버튼)
- 하단 중: 투명도 슬라이더 (연/보통/진)
- 하단 우: 브러시 크기 [●][●●][●●●] + [🖼배경변경]
```

### 6. 영역 색칠
```
영역 색칠놀이 화면을 만들어줘.
- 상단바: ◀뒤로 / "영역 색칠놀이" / 💾저장
- 도안 선택: 가로 스크롤 썸네일 (고양이/강아지/자동차/해바라기/사과)
- 메인: SVG 도안 (영역마다 터치 가능, 채워지면 fade-in)
- 하단: 12색 팔레트
- 진행바: ████░░ 5/12 영역 + 💡힌트 버튼
```

### 7. 한글 학습 서브메뉴
```
한글 학습 서브메뉴 화면을 만들어줘. 색칠놀이 서브메뉴와 같은 레이아웃.
- 6개 카드(3×2): 자음 익히기 ㄱㄴㄷ / 모음 ㅏㅓㅗ / 따라쓰기 ✏️
  / 글자 만들기 ㄱ+ㅏ=가 / 단어 맞추기 🍎=사과? / 단어 카드 🃏
```

### 8. 자음 익히기 활동
```
자음 익히기 활동 화면을 만들어줘.
- 상단바: ◀뒤로 / "자음 익히기 Lv.1" / ⭐별
- 중앙: 거대한 "ㄱ" + 우측에 "기역!" 음성표시 🔊
- 그 아래: 🦒기린 연관 그림
- 좌우: ◀이전 / 다음▶ 큰 버튼
- 하단: 14자 자음 네비게이션 (학습완료는 ⭐표시)
```

### 9. 숫자 덧셈 활동
```
기초 덧셈 활동 화면을 만들어줘.
- 상단: ◀뒤로 / "기초 덧셈 Lv.1" / ⭐별
- 중앙 문제: 🍎🍎 + 🍎🍎🍎 = ? (그림 + 숫자 병기 "2 + 3 = ?")
- 4지선다 큰 카드: [3][4][5][6]
- 하단 진행: ●●●○○○○○○○ 3/10
```

### 10. 코딩 놀이
```
코딩 놀이 스테이지 화면을 만들어줘.
- 좌측: 5×5 격자맵 (🏠캐릭터, ■장애물, ⭐목표)
- 우측 상단: 명령 순서 영역 (예: → → ↓ ↓ →)
- 우측 하단: [▶실행] [🗑초기화] 버튼
- 화면 하단: 4개 방향 블록 ⬆⬇⬅➡ (80×80, 드래그 가능 느낌)
```

### 11. 카드 뒤집기 (두뇌게임)
```
카드 뒤집기 게임 화면을 만들어줘.
- 상단: ◀뒤로 / "카드 뒤집기 Lv.1" / ⭐별
- 정보: "시도 횟수: 3   짝 찾기: 1/6"
- 3×3 카드 그리드 (일부는 ❓뒷면, 일부는 🐱앞면)
- 카드 뒤집기 3D flip 느낌 강조
```

### 12. 피아노 연주
```
피아노 연주 화면을 만들어줘.
- 상단: ◀뒤로 / "🎵 피아노" / ⭐별
- 모드 탭: [🎹자유연주] [🎼따라치기] [🎵동요]
- 메인: 1옥타브 피아노 건반 (흰건반 8개 + 검은건반 5개)
- 각 흰건반 아래: 도/레/미/파/솔/라/시/도 + 무지개 색상 가이드
```

### 13. 결과/칭찬 화면
```
활동 완료 후 칭찬 화면을 만들어줘.
- 중앙 상단: ⭐⭐⭐ 3개 별 (spring 애니메이션 느낌)
- 큰 텍스트: "🎉 잘했어! 🎉"
- 정보 카드: "오늘 받은 별: 3개 / 총 별: 41개"
- 큰 버튼 2개: 🏠홈으로 / 🔄다시하기
- 배경: 🎊🎉✨ 컨페티 파티클 흩날림
- 배경색: 노랑→오렌지 그라데이션
```

### 14. 부모 설정
```
부모 설정 화면을 만들어줘. (어른용이므로 약간 차분한 톤)
- 상단: ◀닫기 / "부모 설정"
- 카드 섹션 5개:
  1) ⏱ 사용시간 제한: 라디오 (10분/20분/30분/무제한)
  2) 🔊 음량: 배경음/효과음/음성안내 3개 슬라이더
  3) 📊 학습 리포트: 사용시간/주요 활동/획득 별
  4) 🔒 카테고리 관리: 10개 토글 ✅/☐
  5) 🗑 데이터 관리: [갤러리 초기화] [진행 초기화] 빨간 버튼
```

### 15. 내 갤러리
```
내 갤러리 화면을 만들어줘.
- 상단: ◀뒤로 / "🖼 내 갤러리" / ⭐별
- 4열 그리드 썸네일 (저장된 색칠 작품)
- 각 썸네일: 이미지 + 작은 🗑삭제 버튼 + 날짜
- 빈 상태: "아직 작품이 없어요. 색칠하러 가볼까?" + 색칠놀이로 이동 버튼
```

## 🚀 사용 팁

1. **새 대화 시작** → 공통 컨텍스트 한 번 붙여넣기
2. **화면 요청은 한 번에 하나씩** (529 에러 회피, 품질 향상)
3. **톤 결정 전**: 화면 1~2개를 톤 A/B/C로 만들어보고 비교
4. **톤 결정 후**: 나머지 화면은 "위와 같은 톤으로" 명시
5. **수정 요청은 짧게**: "버튼을 더 크게", "배경을 좀 더 부드럽게" 식으로 점진적 개선
