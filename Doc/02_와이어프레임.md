# KidsWeb - 와이어프레임

> 모든 화면은 **태블릿 가로모드(1024x768)** 기준으로 설계
> 터치 타겟: 최소 64x64px | 폰트: 최소 20px

---

## 2. 메인 화면 (홈) — 월드맵 "곰곰이의 사계절 마을"

> 가로 스크롤 파노라마 맵. 전체 폭 약 4200px 중 한 화면(1024px)에 일부만 보임.
> 아래는 봄 동산 구간이 화면에 들어온 상태.

```
┌──────────────────────────────────────────────────┐
│  곰곰이의 사계절 마을                    ⭐ 별: 38 │
│                                                  │
│ ◀──────────────  가로 스크롤  ──────────────▶     │
│                                                  │
│   🌸 봄 동산  ░░░░░░░░░░░░  ☀️ 여름 바다 ▒▒▒▒     │
│                                                  │
│              ┌───────────────┐                   │
│              │오늘은 색칠 언덕 │ ← 추천 말풍선     │
│              │  어때?         │                   │
│              └───────────────┘                   │
│                                                  │
│      🎨            🔷            🎵       │ 📚    │
│   색칠 언덕      모양 꽃밭      노래 폭포  │글자나무│
│   ⭐7 🌸        ⭐2           (흐릿/미방문)│  숲   │
│                                                  │
│   🏡        🐻                                    │
│  곰곰이집   곰곰이 (길 따라 이동)                  │
│ ─────────────────────────────────────────────    │
└──────────────────────────────────────────────────┘

구성요소:
- 상단: 맵 제목 "곰곰이의 사계절 마을" + 누적 별 카운터(우상단 고정)
- 본문: 가로 스크롤되는 긴 파노라마 맵
  - 계절 구역 3개: 🌸봄 동산 → ☀️여름 바다 → 🍂가을 숲 (배경 색감으로 구분, 경계는 그라데이션)
  - 장소 10개: 각 계절 구역에 건물/자연물 일러스트로 배치
    · 봄: 색칠 언덕 🎨 / 모양 꽃밭 🔷 / 노래 폭포 🎵
    · 여름: 글자나무 숲 📚 / ABC 모래사장 🔤 / 숫자 산 🔢
    · 가을: 로봇 공장 🤖 / 수수께끼 동굴 🧩 / 반짝 등대 💻 / 친구 광장 💬
  - 장소 꾸미기 4단계: 새싹(흐릿/미방문) → 자람(또렷/방문) → 활짝(🌸 별5+) → 반짝(✨ 별15+)
  - 각 장소 아래 별 뱃지(그 장소 누적 별)
- 곰곰이(🐻): 맵 위에 서 있다가 장소 터치 시 그쪽으로 걸어감. 시작점은 곰곰이집(🏡)
- 추천 말풍선: 가장 덜 가꾼 장소 1곳을 추천, 그 장소가 통통 튐
- 배경: 계절별 색감 + 시간대별 하늘 변조 (아침-낮-저녁)
- 진입 시 오늘 실제 계절 위치로 자동 스크롤
```

### 월드맵 인터랙션
| 요소 | 동작 | 결과 |
|------|------|------|
| 빈 곳 좌우 드래그/스와이프 | 가로 스크롤 | 봄 ↔ 여름 ↔ 가을 이동 |
| 장소 | 터치 | 곰곰이가 걸어가 도착(1~2초) → 서브메뉴 진입 |
| 곰곰이 | 터치 | 랜덤 인사말 + 음성 |
| ⚙ 부모설정 | 3초 길게 누르기 | 산수 문제 → 설정 화면 |
| 별 카운터 | 터치 | 스티커 수집 화면 이동 |

> 빠른 진입(부모 설정): ON이면 곰곰이 걷기를 생략하고 장소 터치 즉시 서브메뉴로 진입.
> 잠금 없음: 10개 장소 모두 처음부터 자유 접근. 계절은 시각적 구역일 뿐.
> 상세 설계: `docs/superpowers/specs/2026-05-20-worldmap-redesign-design.md`

```
┌──────────────────────────────────────────────────┐

│  └──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘ └────┘ │
│                                                  │
│  브러시 크기: [●] [●●] [●●●]    [🖼배경변경]     │
│              소    중    대                       │
└──────────────────────────────────────────────────┘

구성요소:
- 상단 바: 뒤로 / 제목 / 되돌리기(Undo) / 초기화(색칠만 지움) / 저장
- 좌측 메인: 2개 레이어로 구성된 캔버스
  - 하단 레이어: 배경 이미지 (터치 불가, 보기 전용)
  - 상단 레이어: 투명 Canvas (여기에 그림을 그림)
  - 지우개는 상단 레이어만 지움 → 배경은 항상 유지
- 우측 도구바: 크레용/붓/펜/지우개 세로 배치 (64x64px)
  - 선택된 도구: 테두리 강조 + 살짝 확대
- 하단 좌: 색상 팔레트 (12색 + 🌈 확장 버튼)
  - 🌈 터치 시 색상 슬라이더 팝업
  - 선택된 색: 체크마크 또는 테두리 강조
- 하단 중: 투명도 슬라이더 (브러시 불투명도 3단계: 연하게/보통/진하게)
- 하단 우: 브러시 크기 3단계 + [배경변경] 버튼
- 🔄 초기화: 색칠만 전부 지우고 배경은 유지
- 💾 저장: 배경 + 색칠 레이어를 합성(merge)하여 PNG로 갤러리 저장
```
